# Бизнес-домены в скоринге вакансий и кандидатов

Исследование и MVP подхода, где бизнес-домены из резюме и вакансий сравниваются как узлы графа, а не как строки

| Файл | Что внутри |
|---|---|
| `тестовое отчет.pdf` | короткий отчет для чтения, суть, графики, результаты и рекомендация |
| `research_for_human.md` | выжимка исследования на один экран |
| `research_for_ai.md` | полный ресерч, литература, сравнение вариантов, архитектура и подробные итоги эксперимента в разделе 11 |
| `business_domains_mvp.ipynb` | пайплайн с кодом и выводами, демо на примере из условия, крайние случаи и прогон на датасете |

Блокнот запускается в окружении `.venv`, а модели и датасет скачивает вторая ячейка блокнота
